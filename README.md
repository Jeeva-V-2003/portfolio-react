# Jeeva V - Portfolio

A stunning, modern portfolio website built with React, Vite, and Framer Motion.

## 🎨 Features

- **Beautiful Animations:** Smooth Framer Motion animations
- **Modern Design:** Glassmorphism with animated gradient backgrounds
- **Fully Responsive:** Perfect on all devices
- **Fast Performance:** Built with Vite for optimal speed
- **Comprehensive Skills:** Complete data engineering & AI expertise showcase

## 🛠️ Tech Stack

- **React 18** - UI library
- **Vite** - Build tool
- **Framer Motion** - Animations
- **React Icons** - Icon library

## 🚀 Quick Start

### Install Dependencies
```bash
npm install
```

### Run Development Server
```bash
npm run dev
```

### Build for Production
```bash
npm run build
```

### Preview Production Build
```bash
npm run preview
```
